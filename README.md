# Public Transport Demand Predictor

> **SDG 11 — Sustainable Cities and Communities**  
> A machine learning prototype that predicts bus ridership to support smarter, greener urban transport scheduling.

---

## ⚠️ Synthetic Data Disclaimer

> This prototype uses an **entirely synthetic** dataset generated by `src/generate_dataset.py`.  
> It **does not** represent real passenger observations from any transit authority.  
> All reported patterns, trends, and model metrics are illustrative only.

## 🚀 Quick Start

### Prerequisites

- Python **3.10** or **3.11** recommended
- pip

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the full pipeline (generate data + train models)

```bash
python run_pipeline.py
```

This will:
- Generate ~65,000 synthetic records across 5 routes and 2 years
- Clean, encode, and split the data chronologically
- Train and compare 4 models (Baseline, Linear Regression, Decision Tree, Random Forest)
- Save the best model and all artefacts to `models/` and `assets/`

### 3. Launch the dashboard

```bash
streamlit run app.py
```

*On Windows with Python 3.14:*
```powershell
& "C:\Users\OMKAR\AppData\Local\Python\pythoncore-3.14-64\python.exe" -m streamlit run app.py
```

Open your browser at **http://localhost:8501**

### 4. Run instant predictions via CLI

```powershell
& "C:\Users\OMKAR\AppData\Local\Python\pythoncore-3.14-64\python.exe" src/predict.py --route R01 --hour 8 --weather Rainy --temp 24.0
```
Or interactively:
```powershell
& "C:\Users\OMKAR\AppData\Local\Python\pythoncore-3.14-64\python.exe" src/predict.py --interactive
```

## 🌍 Using a Real Dataset

To replace the synthetic data with real ridership data:

1. Prepare a CSV with **at minimum** these columns:

   | Column | Type | Description |
   |--------|------|-------------|
   | `Date` | YYYY-MM-DD | Service date |
   | `Route_ID` | string | Route identifier |
   | `Hour` | int (0–23) | Departure hour |
   | `Day_of_Week` | string | e.g. "Monday" |
   | `Is_Weekend` | 0/1 | Weekend flag |
   | `Temperature` | float | °C |
   | `Weather` | string | Clear/Cloudy/Rainy/Foggy |
   | `Is_Holiday` | 0/1 | Public holiday flag |
   | `Passenger_Count` | int | Actual boardings |

2. Save it as `data/transport_demand_synthetic.csv`  
   *(or update `RAW_CSV` path in `src/preprocess.py`)*

3. Re-run the pipeline:
   ```bash
   python run_pipeline.py
   ```

## 📊 Machine Learning Models

| Model | Description |
|-------|-------------|
| **Baseline (Mean)** | Predicts the training-set mean — sanity check |
| **Linear Regression** | Assumes linear relationships between features and ridership |
| **Decision Tree** | Captures non-linearity; risk of overfitting |
| **Random Forest** ✅ | Ensemble of 150 trees; best RMSE on test set |

**Selection criterion:** Lowest RMSE on the **chronologically held-out** test set (last 20% of dates). RMSE penalises large errors, which is critical for capacity planning.

## ⚖️ Limitations

- Dataset is **synthetic** — real-world accuracy requires real data
- Model is not tuned — hyperparameter optimisation would improve RMSE
- No external data (special events, roadworks) is included
- Predictions should be validated against actual counts before operational use
